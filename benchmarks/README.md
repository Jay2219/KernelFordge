# KernelForge // Stanford KernelBench Evaluation Artifacts

This dataset repository contains verifiable benchmark telemetry generated by **KernelForge**—an autonomous GPU kernel synthesizer and memory-roofline compiler—evaluated across **Stanford KernelBench** Level-1 and Level-2 primitives.

## Benchmark Configuration

| Parameter | Specification |
| :--- | :--- |
| **Target Hardware** | NVIDIA A10G (24GB VRAM, 600 GB/s Peak HBM2) |
| **Compiler Backend** | OpenAI Triton 3.0.0 / PyTorch 2.4.0 (CUDA 12.4) |
| **Numerical Parity Contract** | `torch.testing.assert_close(triton_out, eager_out, rtol=1e-3, atol=1e-3)` |
| **Latency Measurement Harness**| `triton.testing.do_bench(warmup=10, rep=50)` (CUDA event timers) |
| **Roofline Saturation Formula**| $\text{Saturation \%} = \frac{\text{Bytes Transferred} / \text{Latency}}{\text{Peak Wire Bandwidth}} \times 100$ |

## Benchmark Primitives Evaluated

1. **Level-1: LLaMA-3 Fused RMSNorm (`[32, 4096]`)**  
   Fuses sum-of-squares reduction and elementwise normalization, keeping the accumulator in on-chip SRAM registers and eliminating 3 intermediate HBM global roundtrips.

2. **Level-1: LLaMA-3 Fused SwiGLU (`[32, 11008]`)**  
   Fuses the non-linear SiLU activation and Hadamard product, avoiding allocating intermediate activation buffers and evaluating the gating equation in a single streaming pass.

3. **Level-1: Safe Online Softmax (`[32, 4096]`)**  
   Online safe-softmax evaluating max tracking, exponential shift, and normalizer summation directly in thread-block shared memory without materializing un-normalized exponent buffers.

4. **Level-2: Fused Pre-RMSNorm + Residual Add (`[32, 4096]`)**  
   Composite subgraph from LLaMA-3 transformer backbone. Fuses the residual accumulation and layer normalization into a single streaming register pass, eliminating 4 sequential HBM memory passes.
